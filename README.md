# Disease Prediction System Using Machine Learning

A beginner-friendly Python + Streamlit project that demonstrates classification using a symptom dataset.

## Dataset replaced

The original tiny synthetic demo dataset has been replaced with the supplied archive's:
- `Training.csv` → `dataset/disease_symptoms.csv` (4,920 rows, 132 symptom features, `Disease` target)
- `Testing.csv` → `dataset/testing.csv` (42 rows, aligned to the same symptom feature order)

The original target column `prognosis` is renamed to `Disease`. The unused `Unnamed` column in `Training.csv` is removed.

## Important health disclaimer

This is an educational project, **not a medical diagnostic tool**. Dataset labels and model predictions may be wrong and are not clinically validated. Do not use this application to diagnose, treat, or rule out a condition. Consult a qualified healthcare professional for health concerns.

## Requirements

- Python 3.10 or later
- Windows, macOS, or Linux

## Run on Windows PowerShell

Extract the ZIP, open PowerShell inside the `DiseasePredictionSystem` folder, and run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_model.py
python -m streamlit run app.py
```

If PowerShell blocks environment activation, run:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train_model.py
.\.venv\Scripts\python.exe -m streamlit run app.py
```

The app normally opens at http://localhost:8501.

## Workflow

1. `train_model.py` loads the training CSV and validates the target column.
2. A Random Forest classifier learns from the 132 symptom features.
3. The model is saved to `models/disease_model.pkl`.
4. The script evaluates the model against the provided `Testing.csv` sample and writes `models/evaluation.json`.
5. `app.py` loads the model and lets users select symptoms to see the model's predicted dataset label.

Accuracy on this small bundled test file is only a software demonstration metric and must not be interpreted as medical accuracy.
